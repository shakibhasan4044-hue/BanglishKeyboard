Banglish Keyboard — প্রাথমিক Android IME প্রজেক্ট

গুরুত্বপূর্ণ:
- এটি একটি প্রাথমিক নমুনা/প্রোটোটাইপ; পূর্ণাঙ্গ Avro/phonetic transliteration engine নয়।
- বাংলা অক্ষরের বোতাম চাপলে উপরের বারে আনুমানিক Banglish দেখায়।
- উপরের সাজেশন চাপলে রূপান্তরিত লেখা বসে; স্পেস চাপলে বর্তমান লেখা Banglish হিসেবে বসে।
- এই সোর্স থেকে APK তৈরি করতে Android Studio/Gradle পরিবেশ দরকার। এখানে APK কম্পাইল করা হয়নি।

কম্পাইল:
1. ZIP আনজিপ করুন।
2. Android Studio-তে project folder খুলুন।
3. Gradle sync শেষ হতে দিন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s)।
5. ফোনে APK ইনস্টল করুন।
6. Settings > System > Languages & input > On-screen keyboard > Manage keyboards থেকে Banglish Keyboard চালু করুন।
7. কোনো লেখা লেখার জায়গায় কিবোর্ড আইকন/ইনপুট মেথড থেকে Banglish Keyboard বাছুন।

প্রাইভেসি:
এই নমুনায় INTERNET permission নেই এবং নেটওয়ার্কে লেখা পাঠায় না।
